# ♻️ Lixo Eletrônico Mossoró ♻️

Uma plataforma web informativa e interativa desenvolvida para conscientizar a população sobre o impacto do **e-waste** (resíduos eletroeletrônicos) e facilitar a localização de pontos de recolha e ecopontos em **Mossoró - RN** e região.

---

## 📌 Sobre o Projeto

O acúmulo e o descarte incorreto de equipamentos eletrónicos (como telemóveis, computadores e eletrodomésticos) representam um grave risco para o meio ambiente e para a saúde pública devido à presença de metais pesados.

O **Lixo Eletrônico Mossoró** foi criado para resolver esse problema a nível local, oferecendo:
* **Conscientização:** Explicação clara sobre o que é o lixo eletrónico e os seus perigos.
* **Mapeamento de Pontos:** Um sistema de busca dinâmico para encontrar pontos de recolha e ecopontos no Rio Grande do Norte.
* **Alternativas Sustentáveis:** Dicas práticas sobre reciclagem, reutilização e reparação de dispositivos.
* **Encaminhamento Nacional:** Links diretos para os localizadores oficiais da ABREE e Green Eletron para outras regiões do país.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido com tecnologias web fundamentais (Vanilla Stack), garantindo leveza, rapidez e alta compatibilidade:

* **HTML:** Estruturação semântica e acessível do conteúdo.
* **CSS:** Design responsivo, variáveis CSS, animações modernas e tipografia otimizada (Google Fonts: *Sora*, *Inter*, *IBM Plex Mono*).
* **JavaScript :** Manipulação dinâmica do DOM, filtragem de pontos de recolha por estado/cidade e animações de entrada com *Intersection Observer*.
